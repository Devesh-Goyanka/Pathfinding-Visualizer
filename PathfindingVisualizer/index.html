WHAT POWERS THIS WEBSITE

The DSA behind every move

Each colour on the grid comes from a data structure or a step in the graph search. These cards give a quick explanation before you explore the code and report.

01 / MODEL

Grid as a graph

A two-dimensional array stores each cell. Open cells act as vertices; legal up, down, left, and right steps act as edges. A wall blocks that cell from neighbour generation.

02 / FRONTIER

Queue and stack

BFS uses a first-in, first-out queue to search in distance layers. DFS uses a last-in, first-out stack and a direction cursor to follow one branch, then backtrack.

03 / PRIORITY

Min-heap

Dijkstra and A* share a min-heap priority queue implemented in JavaScript. Dijkstra orders by cost so far; A* orders by cost so far plus Manhattan distance.

04 / ROUTE

Visited and parent

Visited flags prevent repeated work. Cost arrays track best-known distances, and parent indices let the website trace backward from the goal and draw the final route.

Guarantee reminder: BFS, Dijkstra, and Manhattan A* return an optimal route under this website's four-way, unit-cost rules. DFS can find a route, but it does not guarantee the shortest one.
